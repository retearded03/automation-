# Privacy Policy

_Last updated: November 17, 2026_

yt-autopilot ("the app") is a personal automation tool operated by the owner of a single YouTube
channel for use with that channel only.

## Data the app accesses

- **Google / YouTube:** with the owner's consent, the app requests the OAuth scope
  `https://www.googleapis.com/auth/youtube.upload`, which is used solely to upload videos and set
  thumbnails on the owner's own channel. The app does not read, analyze, or store any other YouTube
  data from the owner's account, and does not access any other user's account.
- **Public data:** the app reads publicly available information (YouTube "most popular" video titles,
  tags and statistics, public encyclopedia articles, and royalty-free stock media search results) to
  choose topics and create original videos.

## Storage and sharing

- The OAuth refresh token is stored as an encrypted secret in the owner's GitHub repository and is used
  only by the app's automated workflow.
- No personal data is sold, shared with third parties, or used for advertising.
- Generated videos are published on YouTube and are subject to the
  [Google Privacy Policy](https://policies.google.com/privacy).

## Use of YouTube API Services

The app uses YouTube API Services. By using the app you also agree to the
[YouTube Terms of Service](https://www.youtube.com/t/terms). Access can be revoked at any time at
<https://myaccount.google.com/permissions>.
