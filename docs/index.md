# yt-autopilot

yt-autopilot is a private automation tool used by a single YouTube channel owner to publish
original short educational videos ("how things work" facts) to **their own** YouTube channel.

- It writes original scripts based on public encyclopedia sources, narrates them with text-to-speech,
  and assembles them with royalty-free stock footage that is credited in each video description.
- It uses the YouTube Data API only to upload those videos and their thumbnails to the owner's channel.
- It is not offered to the public and does not access any other user's account or data.
