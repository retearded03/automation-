# Lisensi musik latar

Taruh file musik bebas royalti (`.mp3`, `.m4a`, `.wav`, `.ogg`, `.aac`, `.flac`) di folder ini.
Pipeline memilih satu lagu secara acak untuk tiap video. Kalau folder ini kosong, video tetap dibuat
**tanpa musik**, dan Telegram akan mengirim peringatan.

Gunakan hanya musik yang lisensinya jelas mengizinkan pemakaian di YouTube, misalnya dari
**YouTube Audio Library** (YouTube Studio → Audio Library). Pilih lagu yang atribusinya *tidak wajib*,
atau tambahkan atribusinya ke deskripsi.
